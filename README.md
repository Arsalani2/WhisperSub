# WhisperSub

ابزار رونویسی دسته‌ای ویدیو و صوت (گفتار به متن) با مدل **OpenAI Whisper (large-v3)** که برای اجرا در محیط **Jupyter Notebook** (سلول‌به‌سلول) نوشته شده است. خروجی‌های متعدد زیرنویس و متن را تولید می‌کند و گزارش پیشرفت را از طریق ایمیل ارسال می‌کند.

## امکانات

- رونویسی دسته‌ای چندین فایل ویدیویی/صوتی با Whisper `large-v3` (زبان پیش‌فرض: انگلیسی)
- استخراج خودکار صدا با ffmpeg
- تولید خروجی‌های زیر برای هر فایل:
  - زیرنویس: `SRT`، `VTT`، `ASS`
  - متن ساده: `TXT` (با و بدون تایم‌لاین)
  - سند: `PDF` و `DOCX` (با و بدون تایم‌لاین)
  - فایل متادیتا (مدت، تعداد لاین/کلمه/کاراکتر، زمان پردازش و ...)
  - بسته `ZIP` شامل همه خروجی‌ها
- ذخیره‌ی خروجی‌ها در Google Drive (فایل WAV فقط در سشن Colab می‌ماند)
- اعلان ایمیلی (Gmail SMTP) پس از هر فایل و گزارش نهایی
- لاگ کامل اجرا، تخمین زمان باقی‌مانده، و ادامه‌ی پردازش در صورت خطا (مثلاً کمبود حافظه GPU) روی فایل بعدی

## پیش‌نیازها

- یک محیط Jupyter با GPU (ترجیحاً)؛ کد فعلی از APIهای `google.colab` (اتصال Drive و Secrets) استفاده می‌کند، پس همان‌طور که هست در Colab اجرا می‌شود و برای اجرا در Jupyter محلی باید آن بخش‌ها تغییر کنند
- فایل‌های ورودی در Google Drive
- (اختیاری) یک Gmail با **App Password** برای ارسال ایمیل اعلان

حافظه‌ی GPU تقریبی مورد نیاز مدل `large-v3` حدود ۱۱ گیگابایت است. در صورت کمبود، مدل را به `turbo` یا `medium` تغییر دهید.

## راه‌اندازی

1. محتوای `whisper_3_0.py` را سلول‌به‌سلول (هر بخش با `# @title`) در یک نوت‌بوک Jupyter قرار دهید. این فایل از دستورات `!pip` و `!wget` استفاده می‌کند و مستقیماً با `python` اجرا نمی‌شود.
2. Runtime را روی **GPU** بگذارید: `Runtime > Change runtime type > GPU`.
3. در بخش **Secrets** (آیکون کلید) در Colab سه مقدار زیر را اضافه کنید و دسترسی Notebook را فعال کنید:

   | نام Secret | توضیح |
   |---|---|
   | `SENDER_EMAIL` | آدرس Gmail فرستنده |
   | `SENDER_APP_PASSWORD` | App Password جیمیل (نه رمز اصلی حساب) |
   | `RECEIVER_EMAIL` | آدرس ایمیل گیرنده‌ی گزارش‌ها |

   اگر Secretها تنظیم نشوند، رونویسی انجام می‌شود ولی ایمیلی ارسال نمی‌شود.
4. لیست فایل‌ها را در متغیر `input_output_pairs` (سلول ۲) تنظیم کنید:

   ```python
   input_output_pairs = [
       ('/content/drive/MyDrive/Videos/lesson1.mp4', '/content/drive/MyDrive/Subs/lesson1'),
   ]
   ```

   هر جفت به شکل `(مسیر فایل ورودی، پوشه‌ی خروجی)` است. برای ساخت خودکار لیست از یک پوشه می‌توانید از تابع `build_pairs_from_folder(source_folder, destination_root)` استفاده کنید.
5. سلول‌ها را به ترتیب اجرا کنید.

## تنظیمات مهم

| تنظیم | محل | توضیح |
|---|---|---|
| `WHISPER_MODEL_NAME` | سلول ۲ | مدل Whisper (`tiny`، `base`، `small`، `medium`، `large-v3`، `turbo`، ...) |
| `language='en'` | سلول ۴ (`model.transcribe`) | زبان گفتار؛ برای زبان دیگر تغییر دهید (یا حذف کنید تا تشخیص خودکار انجام شود) |
| `condition_on_previous_text=False` | سلول ۴ | برای جلوگیری از تکرار/هذیان مدل در سکوت یا نویز طولانی |
| `SESSION_AUDIO_DIR` | سلول ۲ | مسیر موقت فایل‌های WAV در سشن Colab |

## فرمت‌های ورودی پشتیبانی‌شده

ویدیو: `.mp4 .mkv .avi .mov .webm .wmv .flv .ts`
صوت: `.wav .mp3 .flac .ogg .aac .m4a .amr .aiff .wma .alac`

## ساختار خروجی

برای هر فایل ورودی در پوشه‌ی خروجی مربوطه:

```
<name>- Whisper [Large-v3 Model].srt / .vtt / .ass / .txt / .pdf / .docx
<name>- Whisper [Large-v3 Model]_timeline.txt / .pdf / .docx
<name>_Metadata.txt
<name>_Whisper_Transcription.zip
```

## نکات و محدودیت‌ها

- فونت PDF برابر DejaVu Sans است؛ متن فارسی/عربی با این روش به‌درستی شکل‌دهی (RTL) نمی‌شود و PDF برای خروجی‌های لاتین مناسب‌تر است.
- فایل‌های WAV با پایان سشن Colab پاک می‌شوند.
- هیچ رمز یا کلیدی نباید داخل کد قرار گیرد؛ از Secrets استفاده کنید.
